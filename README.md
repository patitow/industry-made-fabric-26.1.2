# 🏭 Industry Made

Um mod de tecnologia para Minecraft (Fabric / Kotlin) que revoluciona o gameplay survival ao curar a "síndrome do mundo vazio", trazendo industrialização tangível no mundo — da Era do Vapor e Forja Primitiva até a Malha Elétrica Moderna.

## 📖 Documentação & Filosofia do Projeto
Toda a visão de game design, estudo do loop do Minecraft, arquitetura técnica e o roadmap detalhado de desenvolvimento estão documentados em:
👉 **[DESIGN_AND_ROADMAP.md](DESIGN_AND_ROADMAP.md)**

## 🛠️ Ambiente Técnico
- **Minecraft:** 26.1.2
- **Mod Loader:** Fabric Loader 0.19.5
- **Tooling:** Fabric Loom 1.18.2
- **Linguagem:** Kotlin 2.4.20 (`fabric-language-kotlin`)
- **JDK:** Java 25 (configurado em `gradle.properties` apontando para o JDK 25 local)

## 🚀 Compilação & Execução
```bash
# Compilar projeto
./gradlew build

# Iniciar cliente de desenvolvimento
./gradlew runClient
```
